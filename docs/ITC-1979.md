## Indirect Thread Code 

The routines uses five pointers:
    
 VARIABLE     PC  \ program counter
 VARIABLE     SP  \ data parameter stack
 VARIABLE     RP  \ return address stack
 VARIABLE     IP  \ current word been interpreted
 VARIABLE     W   \ next word to be interpreted

 VARIABLE     UP  \ address of user variables

    also those does implicit use a register as the top of data.

    : NEXT1 W @ @ PC ! ;

    : NEXT IP @ @ W ! 2 IP +! ;

    : DOCOL1 -2 RP +! IP @ RP @ ! ;

    : DOCOL DOCOL1 W @ 2+ IP ! NEXT ;

    : EXIT RP @ @ IP ! 2 RP +! NEXT ;

    : PUSH -2 SP +! SP @ ! ;

    : POP SP @ @ -2 SP +! ;

    : EXECUTE   POP W ! NEXT1 ;

    : DOVAR W @ 2+ PUSH NEXT ;

    : DOCON W @ 2+ @ PUSH NEXT ;

    : DOUSE W @ 2+ @ UP + PUSH NEXT ;

    : DODOES DOCOL1 POP IP ! W @ 2+ PUSH NEXT ;

    : LIT IP @ @ PUSH 2 IP +! NEXT ;

    : BRAN IP @ @ IP @ + IP ! NEXT ;

    : ZBRAN 0= IF BRAN ELSE 2 IP +! THEN NEXT ;
