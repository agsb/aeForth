## Indirect Thread Code 

The routines uses five pointers:
    
 VARIABLE     PC  \ program counter
 VARIABLE     SP  \ data parameter stack
 VARIABLE     RP  \ return address stack
 VARIABLE     IP  \ current word been interpreted
 VARIABLE     W   \ next word to be interpreted
 VARIABLE     UP  \ address of user variables

 also those does implicit use a register as the top of data.

    : NEXT1 W @ @ PC ! ;

    : NEXT IP @ @ W ! CELL IP +! ;

    : DOCOL1 -CELL RP +! IP @ RP @ ! ;

    : DOCOL DOCOL1 W @ CELL+ IP ! NEXT ;

    : EXIT RP @ @ IP ! CELL RP +! NEXT ;

    : PUSH -CELL SP +! SP @ ! ;

    : POP SP @ @ -CELL SP +! ;

    : EXECUTE POP W ! NEXT1 ;

    : DOVAR W @ CELL+ PUSH NEXT ;

    : DOCON W @ CELL+ @ PUSH NEXT ;

    : DOUSE W @ CELL+ @ UP + PUSH NEXT ;

    : DODOES DOCOL1 POP IP ! W @ CELL+ PUSH NEXT ;

    : LIT IP @ @ PUSH CELL IP +! NEXT ;

    : BRAN IP @ @ IP @ + IP ! NEXT ;

    : ZBRAN 0= IF BRAN ELSE CELL IP +! THEN NEXT ;
